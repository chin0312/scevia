# DESIGN.md — Scevia visual intent

Values live in `design-system/tokens/tokens.json` (→ generated `tokens.css`). Components and their states live in `design-system/components.md`. This file is the *intent*. It never repeats values.

## Character

**Dark institutional.** A private-wealth app that happens to show event contracts, not a trading terminal. Near-black canvas, quiet grey surfaces, white primary actions, **one violet accent** for selection and Scenario Lab, and vivid green/red used *only* for signed money. Reference set: getquin (surfaces, big figures), Delta (pills, metric tiles), Portfolio Visualizer (section rail, written summaries, comparisons).

## Theme

Dark only (`:root` in tokens.css). There is no light theme. Don't add `data-theme` switches or light-only tokens.

## Brand

Logo and mark live in `design-system/brand/` (`*-on-dark` for the app, `*-on-light` for documents and print). The app header uses the on-dark wordmark at 28px tall. Favicons and app icons are generated by `design-system/brand/make-icons.py` (white mark on the canvas colour). Never recolour, stretch or redraw the mark in code.

## Hierarchy

1. **One question per page.** The page title answers it in plain words ("Where your results come from").
2. **The hero figure** uses `font-size-hero` with smaller decimals, then a signed delta. There is one hero figure per page.
3. **Narrative summary** (Portfolio Visualizer pattern): 2–3 sentences that explain the numbers, with inline links into the detail.
4. **Highlight tiles → charts → tables.** Tables come last and are dense. Charts sit in cards, with the period selector inside the card.
5. Left rail = this page's sections (jump links, with the active one tracked on scroll). Top bar = the four areas plus global utilities on the right.

## Surfaces and elevation

`bg-canvas` (page) → `bg-surface` (cards) → `bg-raised` (popovers, active segment, inputs). Separate elements with a 1px `border-subtle`, not shadows. Shadows are for overlays only. Never nest a card inside a card. Group inside a card with dividers.

## Colour meaning

| Meaning | Token family | Always paired with |
|---|---|---|
| Money up / down | `gain` / `loss` | a `+`/`−` sign |
| YES / NO side | neutral chip + label | the word YES/NO (never colour alone) |
| Selection, scenario, focus | `accent` | — |
| Data caveat | `warn` | an icon + text |
| Category series | `data-1…6` in fixed order | a legend or a direct label |

The accent is never used for profit, and green is never decorative.

## Type

Geist for UI and numbers (tabular figures everywhere), Geist Mono only for IDs, addresses, and price buckets. Use three weights: regular, medium, semibold. Uppercase captions use `tracking-caps`, at most once per card.

## Motion

Use `motion-duration-fast` for hover, `base` for state changes, and `slow` for panel transitions. Use `easing-out` when elements enter. Animate only to show cause and effect, e.g. Scenario numbers tween when a slider moves. Turn motion off under reduced motion (handled by tokens).

## Floor: never ships (lint or review blocks it)

- Raw colours, font sizes, or font families outside tokens (lint error).
- Text contrast below AA (`design-lint --contrast`).
- Gain/loss or YES/NO shown by colour only.
- A probability presented as Scevia's forecast.
- A metric without a definition (ⓘ) or without a coverage caveat when data is partial.
- Removing focus rings.

## Do / Don't

- **Do** show the decimals smaller than the integer part on hero figures. **Don't** use more than one hero figure per page.
- **Do** put "How calculated" beside numbers. **Don't** invent scores (`Risk 87`).
- **Do** use white for primary buttons and the accent for "this scenario / selected". **Don't** use violet gradients, glows, glassmorphism, or neon backgrounds.
- **Do** label lines and bars directly where possible. **Don't** make a legend the only way to read a chart.
- **Do** keep tables dense (36–44px rows) with right-aligned numbers. **Don't** put tables inside nested cards.
- **Do** write plain sentences in summaries. **Don't** add eyebrow chips on every card, emoji, or "AI insights ✨".
